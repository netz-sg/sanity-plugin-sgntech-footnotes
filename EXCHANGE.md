## Title

```
Footnotes & Sources
```

## Description

```
Footnotes and sources as a Portable Text annotation: mark a passage, write the note, optionally add a structured source with title, URL, publisher and date. Numbers are never stored — they are counted from the position in the text, in the editor and at render time, so markers and the list at the end of the article can never drift apart when paragraphs are reordered. Anchor ids come from the annotation key, so a shared link to a footnote survives reordering. Optional merging of repeated sources and an optional popover on the marker.
```
